# 知見同期プログラム(notesync)

要件書 `docs/00_同期プログラム要件.md` の最初の部分です。

| できること | 要件 |
|---|---|
| id のないノートに id をつけ、`id_名前.md` に名前を変える | F-01〜03 |
| `[[名前]]` や別名のリンクを `[[id_名前\|名前]]` に直す(候補が1つのときだけ) | F-03 |
| 同じ名前のノートがあれば知らせる | F-04 |
| 個人vaultの `_仕組み/同期レポート.md` にしたことを書く | F-21 |
| 試し運転(何も変えずにレポートだけ書く) | F-23 |
| 書き換える前に元のファイルを backup に残す(30日) | 安全策 |
| 機密フォルダのリンクは機密の中だけで直す | F-40 |
| 個人設定.md の番号とメンバー.csv が食い違えば止まる | F-44 |
| テンプレートで作ったノートに author を書く | F-03 |
| 集める条件を満たすノートを共有 vault の決まった場所へコピーする(添付の `_仕組み/attachments/<id>/` も) | F-05〜07 |
| 共有に同じ id の別のノートがあれば集めずに知らせる | F-08 |
| 99_archive への移動を共有へ反映する | F-09 |
| 参加プロジェクトと 共通 のノートを `90_共有/` へ配る(自分が書いたものは配らない) | F-10・11 |
| 前回の内容と見比べ、両方変わっていたら上書きせず競合ファイルを置く | F-14・15 |
| 前回の記録が消えても、上書きせずに作り直す | F-34 |
| Obsidian の「今すぐ共有へ」(Ctrl+Shift+S)を受けて、すぐ1回同期する | F-48 |
| vault の名前や場所が変わったら新しい場所を探して config.yaml を直す。見つからなければ止まる | F-50 |
| 設定の場所が vault でない・広すぎる・重なっていれば、何も書かずに止まる | F-55 |
| Publish・Sync・Obsidian Git・外のサービスの鍵・配っていないプラグインを同期レポートで知らせる | F-56 |

共有に直接書かれたノートの拾い直し(F-35)、類似・参考ナレッジ(F-36)、管理者向け週報(F-29)、

まだのもの: exe 化・常駐・タスクトレイ(F-25)、通知(F-22)、取り消し(F-24)、世代ツリー(F-37)、

## 集約と再配布のしくみ

前回同期したときの内容のハッシュを個人 vault の `_仕組み/記録/同期の記録.json` に覚えておき(どの PC からも同じ記録を使う)、
個人側・共有側・前回の3つを見比べる。

| 個人側 | 共有側 | 自分のノート(01〜05) | 配られたノート(90_共有/) |
| --- | --- | --- | --- |
| 変わった | そのまま | 共有へコピー | 編集しないよう知らせる |
| そのまま | 変わった | 個人へ取り込む(他の人の書き足し) | 90_共有/ へコピー |
| 変わった | 変わった | 共有に `<名前>_競合_<人>_<日時>.md` を置いて知らせる | 共有に合わせる(元は backup へ) |

競合は、共有側か個人側のどちらかでまとめると、次の同期でもう一方へ入る。

## 使い方

```
pip install pyyaml
copy config.example.yaml %APPDATA%\知見同期\config.yaml   (中身を自分用に直す)
python -m notesync once --dry-run      # 試し運転。_仕組み/同期レポート.md を見る
python -m notesync once                # 本番を1回
python -m notesync watch --interval 3  # 常駐(3分ごと。Obsidian の Ctrl+Shift+S でその場で1回)
python -m notesync weekly              # 今週の週報(ブラウザで開く HTML)を今すぐ作り直す
python -m notesync weekly --hide 同じノード,機密   # 今回だけ節を外す(--only で載せる節だけにもできる)
```

Windows では、コマンドの代わりに `起動\` の bat をダブルクリックしても動きます(pip install -e は不要。手順はマニュアル 05 の 7・8)。

| bat | 中身 |
| --- | --- |
| `0_準備.bat` | pyyaml を入れ、`%APPDATA%\知見同期\config.yaml` がなければひな形を置いてメモ帳で開く |
| `1_試し運転.bat` | `once --dry-run` |
| `2_1回同期.bat` | `once`(config.yaml が `dry_run: true` なら試し運転のまま) |
| `3_同期を続ける.bat` | `watch --interval 3`。画面を閉じると止まり、Ctrl+Shift+S も効かなくなる |
| `4_週報を作る.bat` | `weekly` |

重い添付(画像・PDF・20MB 未満の動画以外)は `shared_data` の 開発データ/ へ移し、リンクを書き換えます。
priority・previous・generation を自動で書き、期限や状態の変わった日を共有の `_仕組み/記録/ノート履歴/<名前>.csv` に残します。
毎週月曜、`report` を書いた PC ならどれでも、最初に同期した1台が週報(ブラウザで開く HTML 1つと 週報の一覧.html)を作ります。今週の分がもうあれば作りません。

1人が2台以上の PC で同じ個人 vault を使ってかまいません。同期の間は個人 vault に `_仕組み/記録/同期中.lock` を置き、別の PC が同期している間はその回を見送ります。

編集中のノート(最後の保存から `idle_seconds` 秒以内)には触りません。
`00_日誌/デイリー` などの日付ノート、`_仕組み/templates` などの仕組みのフォルダ、配られた `90_共有` は対象外です。
