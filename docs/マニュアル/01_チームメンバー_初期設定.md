# チームメンバー 初期設定

> 正本は rd-notebase の `docs/マニュアル/`。仕様書 v0.42 に合わせています。

最初に1回だけやることです。30分ほどかかります。終わったら [[02_チームメンバー_普段の仕事]] に進みます。

## 始める前に、システム管理者からもらうもの

| もらうもの | 例 |
| --- | --- |
| Box の共有フォルダへの招待 | `Box\チーム\開発ノート_共有\` |
| 自分の個人フォルダを置く場所 | `Box\個人\開発ノート_<自分の名前>\`(共同作業者なし) |
| 配布物の版 | 共有フォルダの `_仕組み/tools/配布/<版>/個人/` |
| 機密フォルダへの招待(担当する案件があるときだけ) | `Box\機密\顧客A\` |
| 同期プログラムが自分の PC で動くかどうか | 動かないうちは「仮運用」(下の 7) |

## 1. Box Drive を用意する

1. Box Drive を入れてサインインし、エクスプローラーの `C:\Users\<ユーザー名>\Box\` に共有フォルダが見えるか確かめます。
2. 共有フォルダ・自分の個人フォルダ・招待された機密フォルダを右クリックし、「オフラインで利用可能にする」をオンにします。Obsidian が速くなり、同期も安定します。
3. `開発データ` と `開発ノート_報告` はオフのままでかまいません。

## 2. 自分の番号を決める

ノートの id の後ろ4文字は、自分の6桁の番号から作ります(例: 229999 → `4XGV`)。

1. ほかの人と重ならない6桁の数字を決めます。社員番号があればそれを使います。
2. 共有フォルダの `_仕組み/tools/同期プログラム/メンバー.csv` に1行足します。名前はこの先ずっと同じ書き方を使います。

```
名前,番号,使い始めた日
佐藤,123456,2026-10-27
```

- 一度使い始めた番号は変えません。変えると、それまでのノートが別の人のものに見えます。
- 辞めた人の番号は使い回しません。

## 3. 個人 vault を作る

1. 個人フォルダを置く場所に、空のフォルダ `開発ノート_<自分の名前>` を作ります。
2. 配布物の `_仕組み/tools/配布/<版>/個人/` の中身を、すべてそこへコピーします(`.obsidian` という隠しフォルダも含めます。エクスプローラーの「表示」→「隠しファイル」をオンにすると見えます)。
3. `_仕組み/個人設定.md` をメモ帳か Obsidian で開き、先頭の2行を書きます。

```yaml
---
name: "佐藤"          # メンバー.csv と同じ書き方
number: "123456"      # 引用符で囲む(先頭の0が消えないように)
---
```

空のままだと、ノートを作るときに右上に「人の記号が見つかりません」と出ます。

## 4. Obsidian で個人 vault を開く

1. Obsidian を入れ、「フォルダを保管庫として開く」で個人フォルダを選びます。
2. 設定(左下の歯車)→ コミュニティプラグイン →「制限モードをオフにする」。
3. 「閲覧」から次の14個を探して入れ、それぞれ「有効化」します。設定はもう入っているので、入れて有効にするだけです。

| プラグイン | 何に使うか |
| --- | --- |
| Templater | テンプレートと、Ctrl+K などのキーの中身 |
| QuickAdd | Ctrl+N(種類を選んで新しいノート)、Ctrl+Shift+N |
| Excalidraw | 図(Ctrl+D)とナレッジ図 |
| K-Plex | つながりの図(Ctrl+G) |
| Tasks | チェックボックスを今日のデイリーノートに集める |
| Day Planner | デイリーノートのタイムライン |
| Periodic Notes | デイリーノートと週報を作る |
| Linter | 書式の整え |
| Custom Attachment Location | 貼った写真などの置き場所 |
| Advanced Rename and Delete Handler | Custom Attachment Location に必要 |
| Iconic | アイコン |
| Omnisearch | 全文検索 |
| Commander | 本文の右クリックのメニュー |
| Front Matter Title | 画面に id を出さず、名前だけを出す |

4. Obsidian をいったん閉じて開き直します。

## 5. 手で選ぶ設定

配布物に入れられない設定です。PC ごとに1回だけ行います。

| どこ | すること |
| --- | --- |
| 設定 → Templater | 「Trigger Templater on new file creation」をオン。オフのままだと、ノートの名前が id つきにならない |
| (初めてキーを押したとき) | 「この vault のスクリプトを信頼するか」と聞かれたら「はい」 |
| 設定 → コアプラグイン | Bases・検索・バックリンク・グラフをオン。デイリーノート・テンプレート・Canvas はオフ |
| 設定 → Excalidraw | 下の「図(Excalidraw)」 |
| 設定 → Custom Attachment Location | 下の「貼ったファイルの置き場所」 |
| 設定 → Day Planner | 下の「タイムライン(Day Planner)」 |
| 設定 → Linter | 下の「書式の整え(Linter)」 |

### 貼ったファイルの置き場所(Custom Attachment Location)

ノートに写真や PDF を貼ったとき、そのファイルをどのフォルダに入れるかを決めます。この設定は配布物に入っていないので、手で入れます。

決めたい形はこうです。ノートの id ごとにフォルダを分け、ファイル名は元のまま残します。デイリーと週報(00_日誌)には id がないので、日付のフォルダに入れます。

```
個人 vault/
  _仕組み/attachments/
    0RJG9TLFLR/        ← 貼ったノートの id
      測定結果.pdf      ← 元のファイル名のまま
    日誌/
      2026-10-26/      ← デイリー 2026-10-26 に貼ったもの
      2026-W43/        ← 週報 2026-W43 に貼ったもの
```

1. 設定(左下の歯車)→ 左の一覧のいちばん下の方にある「Custom Attachment Location」を開きます。
2. **Follow Obsidian attachment location** を**オフ**にします。入れたばかりはオンで、オンのままだと下の欄が使われません。
3. **Custom tokens** の欄に、次をそのまま貼ります(ノートの id、日誌なら日付を返す小さな決まりです)。

```
registerCustomToken('attachDir', (ctx) => {
  const file = ctx.app.vault.getFileByPath(ctx.noteFilePath);
  const id = file && ctx.app.metadataCache.getFileCache(file)?.frontmatter?.id;
  if (id) return String(id);
  if (ctx.noteFilePath.startsWith('00_日誌/')) return '日誌/' + ctx.noteFileName;
  return '';
});
```

4. **Location for new attachments** の欄を消して、次をそのまま貼ります。

```
_仕組み/attachments/{{attachDir}}
```

5. **Generated attachment file name** の欄を消して、次をそのまま貼ります。

```
{{originalAttachmentFileName}}
```

6. ほかの欄は触りません。
7. 設定 → ファイルとリンク →「新しいリンクの形式」を「Vault フォルダからの絶対パス」にします。
8. 確かめます。適当なノートに写真を1枚貼り、左の一覧で `_仕組み/attachments/` の下に、そのノートの id(`0R…` で始まる名前)のフォルダができて、写真が元の名前で入っていれば終わりです。今日のデイリーにも1枚貼り、`_仕組み/attachments/日誌/<今日の日付>/` に入ることも確かめます。`{{attachDir` という名前のフォルダができたときや、欄の下に赤い字が出るときは、3 か 4 の貼り方が違うので、もう一度貼り直します。写真が vault の一番上など別の場所に入るときは、2 がオンのままです。

- 前に `_仕組み/attachments/{{frontmatter:{key:'id'}}}` を貼った人は、3 と 4 をやり直します。前の書き方では、id のない日誌に貼ったものが `_仕組み/attachments/` の直下に入ります。直下にたまったものは、同期プログラムが次の同期で `日誌/<日付>/` へ移し、リンクも直します(書いている途中のノートは、手を止めてから)。

- 今の版では、書き方が `${…}` ではなく `{{…}}` に変わっています(この手順は版 17.0.0 の説明書に合わせています)。古い説明の `${…}` を貼るとエラーになります。
- ここで決めるのは、vault の中の最初の置き場所です。重い添付(画像・PDF・20MB 未満の動画以外)は、あとで同期プログラムが vault の外の `開発データ/` へ移します([[02_チームメンバー_普段の仕事]] の「仕事中」)。

### 図(Excalidraw)

図を、同期プログラムや Git が中身を読める形で保存し、ノートに貼れる SVG も自動で作るための設定です。

1. 設定 → 左の一覧の「Excalidraw」を開きます。設定がとても長いので、上の見出しを目印に進みます。
2. **Saving** の見出しの中の **Compress Excalidraw JSON in Markdown**(圧縮)を**オフ**にします。オンのままだと図の中身が読めない文字の列になり、同期プログラムが図の中の言葉(機密の言葉など)を確かめられず、Git でも変わった所が見えません。
3. **Embedding Excalidraw into your Notes and Exporting** の見出しの中の **Export Settings** を開き、**Auto-export SVG**(SVG を自動で書き出す)を**オン**にします。
4. **Basic** の見出しの中の **Excalidraw template file or folder**(ひな形)の欄に、次をそのまま貼ります。Ctrl+D はひな形を自分で選ぶので、これは Excalidraw のメニューから図を作ったときのためです。

```
_仕組み/templates/図.excalidraw.md
```

5. 確かめます。ノートで Ctrl+D を押して図を開き、四角を1つ描いて閉じます。左の一覧で `_仕組み/attachments/<id>/` に `fig_<ノートのファイル名>.excalidraw.md` と `fig_<ノートのファイル名>.svg` の2つがあり(前に作った図は `図.excalidraw.md` と `図.svg` のままです)、`.excalidraw.md` の方を右クリック →「Markdown として開く」で中身に `"type": "rectangle"` のような文字が読めれば終わりです。

### タイムライン(Day Planner)

デイリーノートに書いた時刻つきの予定を、右にタイムラインとして出します。

- 手で入れる設定はありません。Periodic Notes が有効なら、Day Planner はそのデイリーノート(`00_日誌/デイリー/`)を自動で読みます。Obsidian のコアプラグインの「デイリーノート」はオフのままにします。
- 確かめます。今日のデイリーノートに `- [ ] 10:00 - 11:00 打ち合わせ` と書き、Ctrl+P →「Day Planner」と打って「Show timeline」を選びます。右に今日のタイムラインが出て、10時から1時間の箱があれば終わりです。出ないときは、Periodic Notes の設定でデイリーノートがオンになっているか見ます。

### 書式の整え(Linter)

当面は、保存したときに自動で整えない設定にします。テンプレートの属性欄に書いてある説明のコメントを消さないためです。

1. 設定 → 左の一覧の「Linter」を開きます。
2. いちばん上の **General**(全般)のタブで、**Lint on save**(保存時に整形)が**オフ**になっているか見ます。入れたばかりならオフです。オンなら切ります。
3. ほかは触りません。整えたいときだけ、Ctrl+P →「Linter: Lint the current file」で1枚ずつ整えます。
4. 確かめます。Ctrl+N →「イシュー」で新しいノートを作り、Ctrl+S で保存します。属性欄の `status: 未対応        # 未対応 / 対策中 / …` のような行の、`#` から後ろの説明が消えなければ終わりです(本文の表示ではなく、属性欄を「ソース」で見ると見えます)。

- 欄の名前は、プラグインの版によって少し違うことがあります。英語の名前を目印に探してください。

### 2台目の PC で使うとき

自宅と職場など、2台以上の PC で同じ個人 vault を開いてかまいません。2台目の PC では次の3つだけを行います(ほかの設定は vault の中にあるので、Box Drive でそのまま届きます)。

1. Obsidian で「保管庫フォルダを開く」から、Box Drive の中の自分の個人 vault を開く。
2. 設定 → Templater で「Trigger Templater on new file creation」をオンにする(この設定だけは PC ごとです)。
3. 同期プログラムを入れ、その PC 用の `config.yaml` を書く(場所はその PC の Box Drive の場所に合わせる)。

- 2台で同時に同期プログラムが動いても、片方が同期している間はもう片方が待つので、そのままでかまいません。
- 同期プログラムの画面に出る「見送りました: ○○ の PC が同じ個人 vault を同期しています」は、もう1台が同期中という意味で、困りごとではありません。

## 6. 共有 vault を開く

他の人の知見を読むときや、仮運用のときに使います。

1. Obsidian の左下の保管庫の名前 →「保管庫を管理」→ 共有フォルダを開きます。
2. 設定 → ファイルとリンク →「設定フォルダを上書き」を `.obsidian-<自分の6桁の番号>_<PCの記号>`(例: `.obsidian-229999_aa11234567`。番号は個人設定.md の number と同じ、PCの記号は PC ごとに違う英数字。PC の名前や資産番号など)にし、Obsidian を開き直します。人と PC ごとに設定が分かれ、Box で競合しません。2台目の PC でも、その PC の記号で同じことをします。
3. 共有フォルダの `_仕組み/設定/.obsidian/` の中身を、その設定フォルダにコピーし、もう一度開き直します。
4. 4 と 5 と同じようにプラグインを入れて設定します(Day Planner と Periodic Notes は共有では使いません)。

機密フォルダを開くときも同じ手順です。中身は機密フォルダの `_仕組み/設定/.obsidian/` からコピーします。

## 7. 同期プログラムと仮運用

- 同期プログラムが自分の PC で動いていれば、ノートは**個人 vault** に書きます。条件を満たしたものが数分で共有に集まり、他の人のノートは `90_共有/` に届きます。
- まだ動いていなければ(仮運用)、ノートは**共有 vault に直接**書きます。個人 vault はデイリーノートと書きかけだけに使います。同じノートを2人が同時に開いて書かないでください。
- どちらかはシステム管理者に聞いてください。同期プログラムの設定はシステム管理者が手伝います。
- 常駐にする前(手で動かす間)は、Obsidian を使う間 `C:\dev\rd-notebase\sync\起動\3_同期を続ける.bat`(デスクトップのショートカット)を押して、黒い画面を開いたままにします。閉じると同期も Ctrl+Shift+S も止まります。PC を再起動したら押し直します。

## 8. 動くか確かめる

個人 vault で、上から順に試します。うまくいかないものがあれば、金曜の定例で言ってください。

- [ ] Ctrl+N →「ノード」→ 名前「テスト」と打つ。`02_ノード/` に `0R…_テスト.md` ができ、タブと左の一覧には「テスト」とだけ出る
- [ ] 今日のデイリーノートが開ける(Ctrl+P →「today」と打って Periodic Notes の「Open today's daily note」)
- [ ] デイリーノートの「メモ」に `PA66` と書いて選び、Ctrl+K。`[[…|PA66]]` になり、`02_ノード/` にノードができる
- [ ] 何もない行で Ctrl+L を押すと `- [ ] ` ができる
- [ ] 写真を貼ると `_仕組み/attachments/<id>/` に元の名前で入る
- [ ] ノートで Ctrl+D を押すと、16:9 の枠のある図が右に開く
- [ ] `[[まだない名前]]` と書いて Ctrl+S を押すと、右上に「ファイルのないリンク」と出る
- [ ] 本文を右クリックすると「ノードにする」「イシューにする」などのメニューが出る
- [ ] 同期プログラムを動かした状態(手で動かす間は `3_同期を続ける.bat` の画面が開いている状態)で Ctrl+Shift+S(ノートの上の帯の紙飛行機のボタンでもよい)を押すと、右上に「共有へ送りました」と出る

試しに作ったノートは、右クリック →「削除」で消してかまいません(Obsidian のゴミ箱に入ります)。もっと細かい確認は `_仕組み/設定/導入手順.md` の「6. 確かめること」にあります。
