# チームメンバー 初期設定

> 正本は rd-notebase の `docs/マニュアル/`。仕様書 v0.42 に合わせています。

最初に1回だけやることです。30分ほどかかります。終わったら [[02_チームメンバー_普段の仕事]] に進みます。

## 始める前に、システム管理者からもらうもの

| もらうもの | 例 |
| --- | --- |
| Box の共有フォルダへの招待 | `Box\チーム\開発ノート_共有\` |
| 自分の個人フォルダを置く場所 | `Box\個人\開発ノート_<自分の名前>\`(共同作業者なし) |
| 配布物の版 | 共有フォルダの `_仕組み/tools/配布/<版>/個人/` |
| 機密フォルダへの招待(担当する案件があるときだけ) | `Box\機密\顧客A\` |
| 同期プログラムが自分の PC で動くかどうか | 動かないうちは「仮運用」(下の 7) |

## 1. Box Drive を用意する

1. Box Drive を入れてサインインし、エクスプローラーの `C:\Users\<ユーザー名>\Box\` に共有フォルダが見えるか確かめます。
2. 共有フォルダ・自分の個人フォルダ・招待された機密フォルダを右クリックし、「オフラインで利用可能にする」をオンにします。Obsidian が速くなり、同期も安定します。
3. `開発データ` と `開発ノート_報告` はオフのままでかまいません。

## 2. 自分の番号を決める

ノートの id の後ろ4文字は、自分の6桁の番号から作ります(例: 229999 → `4XGV`)。

1. ほかの人と重ならない6桁の数字を決めます。社員番号があればそれを使います。
2. 共有フォルダの `_仕組み/tools/同期プログラム/メンバー.csv` に1行足します。名前はこの先ずっと同じ書き方を使います。

```
名前,番号,使い始めた日
佐藤,123456,2026-10-27
```

- 一度使い始めた番号は変えません。変えると、それまでのノートが別の人のものに見えます。
- 辞めた人の番号は使い回しません。

## 3. 個人 vault を作る

1. 個人フォルダを置く場所に、空のフォルダ `開発ノート_<自分の名前>` を作ります。
2. 配布物の `_仕組み/tools/配布/<版>/個人/` の中身を、すべてそこへコピーします(`.obsidian` という隠しフォルダも含めます。エクスプローラーの「表示」→「隠しファイル」をオンにすると見えます)。
3. `_仕組み/個人設定.md` をメモ帳か Obsidian で開き、先頭の2行を書きます。

```yaml
---
name: "佐藤"          # メンバー.csv と同じ書き方
number: "123456"      # 引用符で囲む(先頭の0が消えないように)
---
```

空のままだと、ノートを作るときに右上に「人の記号が見つかりません」と出ます。

## 4. Obsidian で個人 vault を開く

1. Obsidian を入れ、「フォルダを保管庫として開く」で個人フォルダを選びます。
2. 設定(左下の歯車)→ コミュニティプラグイン →「制限モードをオフにする」。
3. 「閲覧」から次の14個を探して入れ、それぞれ「有効化」します。設定はもう入っているので、入れて有効にするだけです。

| プラグイン | 何に使うか |
| --- | --- |
| Templater | テンプレートと、Ctrl+K などのキーの中身 |
| QuickAdd | Ctrl+N(種類を選んで新しいノート)、Ctrl+Shift+N |
| Excalidraw | 図(Ctrl+D)とナレッジ図 |
| K-Plex | つながりの図(Ctrl+G) |
| Tasks | チェックボックスを今日のデイリーノートに集める |
| Day Planner | デイリーノートのタイムライン |
| Periodic Notes | デイリーノートと週報を作る |
| Linter | 書式の整え |
| Custom Attachment Location | 貼った写真などの置き場所 |
| Advanced Rename and Delete Handler | Custom Attachment Location に必要 |
| Iconic | アイコン |
| Omnisearch | 全文検索 |
| Commander | 本文の右クリックのメニュー |
| Front Matter Title | 画面に id を出さず、名前だけを出す |

4. Obsidian をいったん閉じて開き直します。

## 5. 手で選ぶ設定

配布物に入れられない設定です。PC ごとに1回だけ行います。

| どこ | すること |
| --- | --- |
| 設定 → Templater | 「Trigger Templater on new file creation」をオン。オフのままだと、ノートの名前が id つきにならない |
| (初めてキーを押したとき) | 「この vault のスクリプトを信頼するか」と聞かれたら「はい」 |
| 設定 → コアプラグイン | Bases・検索・バックリンク・グラフをオン。デイリーノート・テンプレート・Canvas はオフ |
| 設定 → Excalidraw | Saving で圧縮(Compress)をオフ。Embed & Export で「SVG を自動で書き出す」をオン。テンプレートを `_仕組み/templates/図.excalidraw.md` に |
| 設定 → Custom Attachment Location | 添付のフォルダを `_仕組み/attachments/${frontmatter:{key:'id'}}`、ファイル名を `${originalAttachmentFileName}` に |
| 設定 → Day Planner | デイリーノートの読み取り元を Periodic Notes に |
| 設定 → Linter | 「保存時に整形」をオフ |

### 2台目の PC で使うとき

自宅と職場など、2台以上の PC で同じ個人 vault を開いてかまいません。2台目の PC では次の3つだけを行います(ほかの設定は vault の中にあるので、Box Drive でそのまま届きます)。

1. Obsidian で「保管庫フォルダを開く」から、Box Drive の中の自分の個人 vault を開く。
2. 設定 → Templater で「Trigger Templater on new file creation」をオンにする(この設定だけは PC ごとです)。
3. 同期プログラムを入れ、その PC 用の `config.yaml` を書く(場所はその PC の Box Drive の場所に合わせる)。

- 2台で同時に同期プログラムが動いても、片方が同期している間はもう片方が待つので、そのままでかまいません。
- 同期プログラムの画面に出る「見送りました: ○○ の PC が同じ個人 vault を同期しています」は、もう1台が同期中という意味で、困りごとではありません。

## 6. 共有 vault を開く

他の人の知見を読むときや、仮運用のときに使います。

1. Obsidian の左下の保管庫の名前 →「保管庫を管理」→ 共有フォルダを開きます。
2. 設定 → ファイルとリンク →「設定フォルダを上書き」を `.obsidian-<自分の名前>`(例: `.obsidian-佐藤`)にし、Obsidian を開き直します。人ごとに設定が分かれ、Box で競合しません。
3. 共有フォルダの `_仕組み/設定/.obsidian/` の中身を、`.obsidian-<自分の名前>/` にコピーし、もう一度開き直します。
4. 4 と 5 と同じようにプラグインを入れて設定します(Day Planner と Periodic Notes は共有では使いません)。

機密フォルダを開くときも同じ手順です。中身は機密フォルダの `_仕組み/設定/.obsidian/` からコピーします。

## 7. 同期プログラムと仮運用

- 同期プログラムが自分の PC で動いていれば、ノートは**個人 vault** に書きます。条件を満たしたものが数分で共有に集まり、他の人のノートは `90_共有/` に届きます。
- まだ動いていなければ(仮運用)、ノートは**共有 vault に直接**書きます。個人 vault はデイリーノートと書きかけだけに使います。同じノートを2人が同時に開いて書かないでください。
- どちらかはシステム管理者に聞いてください。同期プログラムの設定はシステム管理者が手伝います。
- 常駐にする前(手で動かす間)は、Obsidian を使う間 `C:\dev\rd-notebase\sync\起動\3_同期を続ける.bat`(デスクトップのショートカット)を押して、黒い画面を開いたままにします。閉じると同期も Ctrl+Shift+S も止まります。PC を再起動したら押し直します。

## 8. 動くか確かめる

個人 vault で、上から順に試します。うまくいかないものがあれば、金曜の定例で言ってください。

- [ ] Ctrl+N →「ノード」→ 名前「テスト」と打つ。`02_ノード/` に `0R…_テスト.md` ができ、タブと左の一覧には「テスト」とだけ出る
- [ ] 今日のデイリーノートが開ける(Ctrl+P →「today」と打って Periodic Notes の「Open today's daily note」)
- [ ] デイリーノートの「メモ」に `PA66` と書いて選び、Ctrl+K。`[[…|PA66]]` になり、`02_ノード/` にノードができる
- [ ] 何もない行で Ctrl+L を押すと `- [ ] ` ができる
- [ ] 写真を貼ると `_仕組み/attachments/<id>/` に元の名前で入る
- [ ] ノートで Ctrl+D を押すと、16:9 の枠のある図が右に開く
- [ ] `[[まだない名前]]` と書いて Ctrl+S を押すと、右上に「ファイルのないリンク」と出る
- [ ] 本文を右クリックすると「ノードにする」「イシューにする」などのメニューが出る
- [ ] 同期プログラムを動かした状態(手で動かす間は `3_同期を続ける.bat` の画面が開いている状態)で Ctrl+Shift+S(ノートの上の帯の紙飛行機のボタンでもよい)を押すと、右上に「共有へ送りました」と出る

試しに作ったノートは、右クリック →「削除」で消してかまいません(Obsidian のゴミ箱に入ります)。もっと細かい確認は `_仕組み/設定/導入手順.md` の「6. 確かめること」にあります。
