  - Git には説明の .md（ファイル名・大きさ・sha256・クラウド上の場所・公開範囲）だけを入れる。版の履歴はクラウド側に任せる

- [ ] **添付の関連付けを切らさない**
  - 説明の .md の `file` をリンクにする（`file: "[[○○.png]]"`）→ Obsidian での改名に追従
  - push 時に sha256 で照合：指す先が無い説明の .md は、同じ sha256 のファイルに付け直す（Obsidian の外での改名・`50_data` にも効く）
  - 説明の .md が無い添付（Obsidian で貼っただけの画像）に、push 時に自動で作る（貼ったノートの公開範囲を引き継ぐ）
  - 貼った画像を push 時に縮小・形式変換（長辺 1920px 程度、JPEG/WebP）、Obsidian で貼った画像にも sha256 の重複防止
  - 実機確認：除外（`userIgnoreFilters`）した `40_attachments` でも、改名でリンクが更新されるか
- [ ] **案件ごとのアーカイブ（notebase archive）**
  - きっかけ：registry の案件を「完了」にしたら、各人の notebase に候補を出す（各人が自分の vault の分を移す）
  - 起点は案件のまとめ markdown。リンクを2段目以降もすべてたどる（他の案件のまとめも含めて止めない）
  - **依存関係のマップを表示**し、ノート・添付ごとに手動で「移す／写しを取る／残す」を選べるようにする
    - 初期値：この案件だけのもの＝移す。他の案件（`project` プロパティかリンク）と被るもの＝写し。続いている案件のまとめ＝残す
    - マップ上で案件ごとに色分け、被りを強調
  - 移す：vault から消してアーカイブへ（`アーカイブ/<人>/<案件>/`、Git は案件ごとの凍結リポジトリ）
  - 写し：vault に残し、「案件完了時点の写し」としてアーカイブに保存（元の id・版（コミット）・sha256 を記録）
  - 添付：使っているノートが全部移るなら移す、1つでも残るなら写し。保存は sha256 で一つにまとめる（写しても実体は1つ）
  - アーカイブ時に一覧（元の場所・ファイル名・sha256・移した日）を残す（ISO 9001 の記録）。取り消しもできるように
  - 残ったノートから移したノートへのリンクは `_refs/` のスタブで補う。サーバの索引・Web 閲覧・PDF には全部残す
  - 案件に属さないノート（daily/weekly、どこにもリンクされないメモ）は年度ごとの別ルール（例：2年より前）で候補に
