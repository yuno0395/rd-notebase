# 知見ノートの書き方(現場向け1枚) v0.3

> この Markdown が正本です。共有 vault の直下に置きます。仕組みの全体と理由は 00_仕様書.md(まとめ役向け)にあります。
> 作成: Yu ・ 書き出し: 2026-10-24 ・ 下書き: https://claude.ai/artifact/5pqwnAkX8wwwpcCx7MoGX1

覚えることは3つだけです。属性欄(先頭の --- で囲まれた所)は手で直さなくて大丈夫です。

**よく使うキー**

| キー | すること |
| --- | --- |
| Ctrl+L | 行をチェックボックス `- [ ]` にする。もう一度押すと完了 |
| Alt+K | 選んだ語を `[[ ]]` で囲み、その場でノードを作る(質問なし) |
| Alt+I / Alt+T | 選んだ行を、その場でイシュー / タスクにする(質問なし。イシューのインパクトは「未判定」で入り、金曜に決める) |
| Alt+D | このノートの図(Excalidraw)を開く。なければ作る |
| Alt+J | 今の仕事が「目的への貢献が一番大きく、自分で進められ、少しチャレンジング」かを確かめる |

## 1. メモを書く

- 思いついたことは、**今日のデイリーノートの「メモ」**か、**今やっている仕事のノート**に書く。inbox にファイルを作らなくてよい。
- 出てきた物や値の名前(PA66、保圧、ヒケ など)は Alt+K で `[[ ]]` にする。打つだけでもよい。
- 「5分後にやる」ような細かい仕事は Ctrl+L でチェックボックスにする。期日をつけると(`📅 2026-10-24`)、その日のデイリーノートに集まる。
- 写真・図・PDF・Excel・pptx は、ノートに貼るかドラッグするだけ。ファイル名はそのままでよい。どこに置くか迷うファイルだけ `00_inbox/` に置く。
- スマホの写真は、Box アプリで共有の `開発ノート_共有/00_inbox/` に上げ、PC でノートにドラッグする。
- 図は Alt+D で描く。枠1つが「1枚」。画像や Excel のグラフは Ctrl+V で貼れる。
- 顧客から受け取った図面・仕様書は、機密フォルダに置く。ノートには顧客名や図番を書かない。顧客名を伏せた数値(例: ある顧客の設備は月2回止まる)は書いてよい。

## 2. イシューを作る(心配なこと、リスク)

急ぐときは、行を選んで Alt+I。インパクトは「未判定」で入り、金曜にまとめ役が決めます。ゆっくり作るときはボタン「イシュー」を押して、4つの質問に答えます。

| 質問 | 答え方 |
| --- | --- |
| 名前は？ | 「〜のおそれ」で終わる文。例: 肉厚部のヒケで外観不良になるおそれ / スリープ電流が大きく電池が3年もたないおそれ |
| どの価値を邪魔する？ | 目的の下にある「価値の仮説」(例: 電池3年、後付け10分)の一覧から選ぶ |
| インパクトは？ | 上から順に はい / いいえ で答える。答えで開発の方向が変わる → **方針**。候補がいくつか消える → **絞込**。解けないと出荷できない → **出荷**。遅れやコスト増になる → **中**。改善になる程度 → **小** |
| すぐできる？ | すぐ: 1週間以内に今の人・設備・予算で試せる / 時間がかかる |

- **迷ったら「出荷」「すぐ」**。
- 作るとノートの最後に「先に読むもの」(他のプロジェクトの似たイシューや、使える知見)が出ます。着手する前に目を通してください。
- DR や打ち合わせの指摘は、インパクト中以上だけイシューにします。小は議事録に残すだけでよいです。

## 3. タスクを終える

**タスクのノートを作るのは、半日以上かかってリスクを下げる仕事だけ**です。それ以外はチェックボックスで十分です。進めるタスクは1人3件まで。回答待ち・納品待ちのタスクは status を「待ち」にすれば、3件に数えません。迷ったら Alt+J で、今の仕事でよいか確かめます。

終わったら、インパクトに合わせて結果を残します。

| イシューのインパクト | 残すもの | 確認 |
| --- | --- | --- |
| 方針・絞込・出荷 | 結果図(Excalidraw、画面1枚)とナレッジ。わかったことを関係するノードにも書く | もう1人に見てもらう |
| 中 | タスクの「結果」欄に、写真と数値を3行 | 自分で読み返す |
| 小 | タスクの「結果」欄に1行 | 自分で読み返す |

- 最後にタスクの status を「完了」にする。やめると決めたら「中止」にする(消さない)。
- イシューの status(未対応 / 対策中 / 低減済み / 解消 / 中止)も直す。

## 困ったとき

- 共有されないノートは、今日のデイリーノートの先頭に理由と直し方が出ます。
- 共有したくないノートだけ、属性欄に `visibility: 個人` と書きます。
- わからないことはまとめ役に聞いてください。押し間違えたら、ボタン「直前の作成を取り消す」で消せます。
