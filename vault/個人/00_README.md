# 個人 vault

自分だけが見るフォルダです。メモ・イシュー・タスクはここで書きます(仕様書「フォルダ構成」)。

| フォルダ | 置くもの |
| --- | --- |
| 00_PIP/ | 自分だけのフォルダ(PIP)。同期プログラムは読まないので、絶対に共有されない |
| 00_PIP/デイリー/ | デイリーノート。メモはここの「メモ」に書く |
| 00_PIP/メモ/ | 共有しないメモ(Ctrl+N の「メモ(共有しない)」)と、作るときに PIP を選んだノート。共有したくなったら右クリックか上の帯の「共有する」 |
| 00_週報/ | 週報。visibility(Internal use only かプロジェクト名)どおりに共有される |
| 00_inbox/ | 行き先のわからないファイル(写真・pptx など)と、プロジェクトを選ばずに作ったノート(一時置き場) |
| <プロジェクト>/ | プロジェクトのノート。01_目的/・01_設計案/・03_イシュー/・04_タスク/・05_ナレッジ/ と台帳。共有 vault と同じ並び |
| 共通/ | プロジェクトをまたぐもの。02_ノード/(ノードは全部ここ)、03_イシュー/(2つ以上のプロジェクトか「共通」のイシュー)、機密の窓口/ |
| 99_archive/ | 使わなくなったノート(消さずにここへ移す) |
| _仕組み/ | あまり開かないもの。同期レポート、添付、記録、テンプレート |
| _仕組み/個人設定.md | 自分の名前と6桁の番号(id の人の記号になる)。最初に1回だけ書く |

自分のノートも、同期プログラムが配る他の人のノートも、共有と同じ場所に並びます。author に自分がいないノートが他の人のノートで、開くと読む画面になります。書き足すときは、ノートの上の帯の「自分も作成者に入れて書く」を押します(押さずに書き換えると、次の同期で共有の中身に戻ります)。

ノートを作るときの置き場所は、Ctrl+I・T・H・U なら今のノートから決まり、だれに見せるか(visibility)も今のノートから引き継ぎます。Ctrl+N で作るときは、だれに見せるかを1回選びます(PIP / Internal use only / プロジェクト名。Esc なら PIP)。プロジェクトを選べばそのフォルダに、Internal use only なら 共通/ に、PIP なら 00_PIP/メモ/ に置きます。共有しているノートをやめたいときは、上の帯の「共有をやめる」を押します(もう共有に出した写しは残ります)。置き場所がずれても、同期プログラムが正しいフォルダへ移します。

## はじめに

1. `_仕組み/個人設定.md` の属性欄に、name(自分の名前)と number(自分で決める6桁の数字。例: "229999")を書く。共有の `_仕組み/tools/同期プログラム/メンバー.csv` にも同じ名前と番号を書く。
2. Obsidian でこのフォルダを vault として開き、コミュニティプラグインを入れる(`.obsidian/community-plugins.json` に載っているもの)。設定は入っているので、入れて有効にするだけでよい。
3. 残りの設定は共有 vault の `_仕組み/設定/導入手順.md` のとおりにする。

同期プログラムができるまでは、ノートは共有 vault に直接書き、この vault はデイリーノートと書きかけだけに使います(仕様書「E. 同期プログラムができるまでの仮運用」)。

このフォルダの仕組みのファイル(`_仕組み/templates/` と この README)は、版を出すたびに上書きされます。ノートと `_仕組み/個人設定.md` は上書きされません。
