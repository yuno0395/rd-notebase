# 個人設定

最初に1回だけ、上の属性欄の name と number を書きます。版を当てても上書きされません。

- **number** は自分で決める6桁の数字です(社員番号など)。ほかの人と重ならないようにし、共有の `_仕組み/tools/同期プログラム/メンバー.csv` にも同じ番号を書きます。
- ノートの id の後ろ4文字は、この番号を36進数(0〜9と A〜Z)にしたものです。例: 229999 → `4XGV`、id は `0RDGPG4XGV` のようになります。
- 一度使い始めたら番号は変えません(変えると、それまでのノートと別の人に見えます)。
- 空のままだと、ノートを作るときに「人の記号が見つかりません」と出ます。
