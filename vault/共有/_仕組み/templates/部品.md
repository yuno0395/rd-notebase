## PartsList
parent にこの部品が入っている部品(この Assy を構成する部品)
```base
filters:
  and:
    - '!file.inFolder("_仕組み/templates")'
    - type == "ノード"
    - kind == "部品"
    - 'list(parent).join(" ").contains(this.id)'
formulas:
  alias: 'file.asLink(if(list(aliases).filter(value).length > 0, list(aliases).filter(value)[0], file.basename.replace(/^[0-9A-Z]{6}[0-9A-Z]+_/, "")))'
  amount: 'if(note["単価"] && note["個数"], number(note["単価"]) * number(note["個数"]), "")'
properties:
  formula.alias:
    displayName: 別名
  formula.amount:
    displayName: 金額
views:
  - type: table
    name: PartsList
    order:
      - formula.alias
      - id
      - 個数
      - 単価
      - formula.amount
      - 発注先
      - status
      - PurchaseNo
      - drawing_no
    sort:
      - property: file.name
        direction: ASC
```
