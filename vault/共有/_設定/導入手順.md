# 導入手順

配布物に入っている設定と、手で選ぶ設定です。上から順に行います。✔ は配布物の設定に入っているもの、☐ は手で選ぶものです。

## 1. vault を開く

| vault | 開き方 |
| --- | --- |
| 個人 | 個人フォルダを Obsidian で開く。設定(`.obsidian/`)は入っている |
| 共有 | 共有フォルダを開き、☐ 設定 → ファイルとリンク →「設定フォルダを上書き」を `.obsidian-<名前>`(例: `.obsidian-Yu`)にする。Obsidian を開き直し、この `_設定/.obsidian/` の中身を `.obsidian-<名前>/` にコピーする。人ごとに設定が分かれ、Box で競合しない |
| 機密 | 共有と同じ。中身は機密フォルダの `_設定/.obsidian/` から |

共有・機密の vault では、id の人の記号を、設定フォルダの名前(`.obsidian-<名前>`)からメンバー.csv で引きます。名前はメンバー.csv と同じに書いてください。

## 2. Obsidian の設定

- ✔ ファイルとリンク: Wikiリンクを使う、新しいリンクの形式は「最短パス」、ファイル名変更時にリンクを更新
- ✔ 削除したファイル: Obsidian のゴミ箱(.trash)
- ✔ 新しいノートの場所: 個人は 02_ノード/、共有は 共通/02_ノード/、機密は 06_事実/(まだない `[[水]]` をクリックしたときのため)
- ☐ コアプラグイン: Bases・検索・バックリンク・グラフをオン。デイリーノート・テンプレート・Canvas はオフ

## 3. コミュニティプラグイン

☐ 設定 → コミュニティプラグイン → 制限モードをオフにし、`community-plugins.json` に載っているものを「閲覧」から入れて有効にする。

| プラグイン | 設定 |
| --- | --- |
| Templater | ✔ テンプレートは `_templates`、スクリプトは `_templates/_scripts`。✔ フォルダ名で 目的・ノード・イシュー・タスク・ナレッジ・事実 のテンプレートが入る規則(File regex templates)。☐ 「Trigger Templater on new file creation」を PC ごとに手でオンにする(安全のため設定ファイルでは配れない。オフのままだとノートの名前が id つきに変わらない)。☐ 1回目に「この vault のスクリプトを信頼するか」と聞かれたら、はい |
| Periodic Notes(個人だけ) | ✔ デイリーは 00_daily/、名前 YYYY-MM-DD、テンプレート デイリー。✔ 週報は 00_weekly/、名前 GGGG-[W]WW、テンプレート 週報 |
| Day Planner(個人だけ) | ☐ デイリーノートの読み取り元を Periodic Notes にする |
| Tasks | 既定のまま |
| QuickAdd | ☐ 下の「QuickAdd のボタン」を作る |
| Excalidraw | ☐ Saving → 圧縮しない(Compress をオフ)。☐ Embed & Export → SVG を自動で書き出す をオン。☐ テンプレートを `_templates/図.excalidraw.md` にする |
| Custom Attachment Location | ☐ 添付のフォルダを `_attachments/${frontmatter:{key:'id'}}`、ファイル名を `${originalAttachmentFileName}` にする。リンクは vault の一番上からのパス |
| Advanced Rename and Delete Handler | 既定のまま(Custom Attachment Location に必要) |
| K-Plex | ☐ 親・友・反論の属性名を `parent`・`friend`・`challenger` にする |
| Linter | ☐ 当面は「保存時に整形」をオフ(属性欄のコメントを消さないため) |
| Iconic | ☐ 当面は既定のまま。type ごとのアイコンはあとで決める |
| Omnisearch | 既定のまま |

## 4. QuickAdd のボタン

☐ QuickAdd の設定で、種類ごとに Template のボタンを作る。どれも「ファイル名」は `{{VALUE}}` にする。テンプレートが id をつけて `id_名前` に直す。

| ボタン | テンプレート | 作る場所(個人) | 作る場所(共有の仮運用) |
| --- | --- | --- | --- |
| 目的 | 目的.md | 01_目的/ | <プロジェクト名>/01_目的/ |
| 価値の仮説 | 価値の仮説.md | 01_目的/ | <プロジェクト名>/01_目的/ |
| ノード | ノード.md | 02_ノード/ | 共通/02_ノード/ |
| イシュー | イシュー.md | 03_イシュー/ | <プロジェクト名>/03_イシュー/ か 共通/03_イシュー/ |
| タスク | タスク.md | 04_タスク/ | <プロジェクト名>/04_タスク/ |
| 議事録 | 議事録.md | 04_タスク/ | <プロジェクト名>/04_タスク/ |
| 実験・試作記録 | 実験・試作記録.md | 04_タスク/ | <プロジェクト名>/04_タスク/ |
| 設計記録 | 設計記録.md | 04_タスク/ | <プロジェクト名>/04_タスク/ |
| ナレッジ | ナレッジ.md | 05_結果/ | <プロジェクト名>/05_結果/ |
| プロジェクト | プロジェクト.md | ― | <プロジェクト名>/(フォルダも作る) |

共有の仮運用で <プロジェクト名> を選ぶには、QuickAdd の「フォルダを選ぶ」をオンにする。

## 5. ショートカットキー

- Ctrl+L(行を `- [ ]` にする)は Obsidian に最初から入っている。
- Alt+K / M / I / T / H / D / S / J は、スクリプトを Yu が確かめてから次の版で入れる。

## 6. 確かめること

導入したら、次を確かめて金曜の定例で報告する。

- [ ] QuickAdd でイシューを作ると、ファイル名が `0R…001_名前.md` になり、属性欄に id が入る
- [ ] 共通/02_ノード/ に手で新しいノートを作っても、テンプレートと id が入る
- [ ] 画像を貼ると `_attachments/<id>/` に元の名前で入る
- [ ] Ctrl+L で、何もない行に `- [ ]` ができる
- [ ] 00_イシュー一覧.base が priority 順に並ぶ
- [ ] 図のひな形を開くと、16:9 の枠が1つある
