# 機密フォルダ

> このフォルダに何があるか、誰が見てよいかを、作った人がここに書く。

- 中身:(例: 顧客A から受け取った仕様書・図面・測定データ)
- 見てよい人:(例: 顧客A 案件の担当営業・担当技術者。Box の共同作業者と同じにする)
- 共有の窓口ノート:(例: 共通/機密の窓口/ の「案件A」。顧客名を使わない呼び名にする)

## 決まり(仕様書「フォルダ構成」)

- 置くのは**事実と原本だけ**。知見(ナレッジ・イシュー・タスク)は置かない。知見は個人・共有のノートに書く。
- 事実ノートは `06_事実/` に作る(type: 事実)。原本は `_仕組み/attachments/<事実ノートの id>/` に置く。重いものもここでよい。
- 個人・共有のノートから指すときは、属性欄に `secret_refs: ["[[案件A]]"]` と、共有の窓口ノートへのリンクを書く。このフォルダの名前、事実ノートの名前・中身・id は書かない。窓口ノートには、見てよい人と社内の当事者だけを書く。
- ここにあるものは、どこへもコピーしない。顧客名を伏せた数値(例: 要求荷重 500N)は共有のノートに書いてよい。
- 古くなったものは消さずに `99_archive/` へ移す。

## Obsidian で開くとき

1. 設定フォルダを `.obsidian-<名前>` にする(Obsidian の「設定フォルダを上書き」)。`_仕組み/設定/.obsidian` の中身をそこへコピーする。
2. `_仕組み/tools/メンバー.csv` に自分の名前と6桁の番号があるか確かめる。id はこれで作る。
